# ZeusSet

Plugin na Paper 1.21.4 (Java 21). Komenda `/zeus [gracz]` daje set Zeusa:
żółta tunika (Ochrona 52, nieznisczalna), drewniany miecz (Ostrość 52, Unbreaking 53, nieznisczalny) i Głowa Zeusa.

Uprawnienie: `zeus.give` (domyślnie OP).
Skórka głowy: `plugins/ZeusSet/config.yml` -> `head-owner`.

Gotowy plik .jar buduje GitHub Actions (zakładka Actions -> ostatni przebieg -> Artifacts -> ZeusSet).
